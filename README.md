# 卖家岛 · Windows 发行

这里仅保存卖家岛的 Windows 安装包、更新签名及发行说明，不包含源码、店铺配置或任何凭据。

## 下载

进入 [banben/windows](banben/windows/) 下载最新安装包并阅读更新说明。

## 应用内更新

从 **0.5.0** 开始，可在卖家岛的 **设置 → 关于 → 检查更新** 检查新版本。程序校验版本绑定签名，下载完成后需要再次确认安装。

0.4.7 及更早版本需要手动安装一次 0.5.0。升级时选择原安装目录，勿先卸载，保留本机配置。

本仓库不保存更新签名私钥。Windows Authenticode 与应用内更新签名不是一回事，安装时可能仍显示未知发布者提醒。
