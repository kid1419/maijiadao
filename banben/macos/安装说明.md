# 卖家岛 0.5.0 · macOS Apple Silicon (M 系列)

本目录提供卖家岛 macOS (M1/M2/M3/M4) 版安装包与签名更新信息。仓库不包含店铺配置、邮箱凭据、开发日志或更新私钥。

## 首次安装

1. 下载同目录的 `卖家岛_0.5.0_aarch64.dmg`，确认来源为 `kid1419/maijiadao`。
2. 打开 DMG，将「卖家岛」拖入「应用程序」文件夹。
3. 首次打开可能提示无法验证开发者（未公证）：**在「应用程序」中右键点击卖家岛 → 打开 → 再点「打开」**；或在终端执行 `xattr -cr /Applications/卖家岛.app` 后再打开。
4. 首次启动会显示设置向导，请填写自己的领星 MCP Key、店铺 ID 与邮箱信息；安装包不内置任何凭据。

## 应用内更新

- 「设置 → 关于 → 检查更新」读取本目录 `latest.json`，下载后校验版本绑定签名，确认后自动替换应用并重启。
- 自动检查更新可关闭；不会自动下载或静默安装。

## 与 Windows 版的差异

- 小岛位于 macOS 菜单栏下方贴顶显示；应用不出现在 Dock，仅托盘常驻。
- 网页打开方式支持系统默认浏览器与 Edge/Chrome/Firefox（需已安装到「应用程序」）。
- 欧利提示弹窗可能短暂获取焦点（Windows 版不会）。
- 开机自启动通过登录项（LaunchAgent）实现。

## 版本文件

- `latest.json`：最新正式版本、发行说明、darwin-aarch64 更新包地址与签名。
- `卖家岛_0.5.0_aarch64.app.tar.gz.sig`：应用内更新包的版本绑定签名。
- `SHA256SUMS.txt`：文件完整性校验值；应用内安全校验以签名为准。

## 已知限制

- 更新签名不等同 Apple 公证/Gatekeeper 认可；应用内更新替换后的应用同样需要首次右键打开。
- 未使用 Apple 开发者证书签名，如系统升级后 Gatekeeper 拦截，重复右键打开步骤即可。
