# 卖家岛 0.5.4 更新说明

**发布日期**：2026-11-25
**安装包**：卖家岛_0.5.4_x64-setup.exe（10,578,791 字节）
**SHA256**：28553A2F093935EB23DFA3E4D6AAF340ECB4FEF877DC92C5BC94AA1173037E3A

## 本轮新功能

- **透明边缘可穿透**：刘海/胶囊/工具栏两侧的透明区域不再拦截底层窗口点击，鼠标划过即可操作后面的应用；移到岛体上立即恢复可交互。
- **拖动吸附 + 位置记忆**：拖动松手时自动吸附屏幕边缘（带落位微弹）；关闭程序再打开，小岛回到你最后拖到的位置。
- **邮件正文阅读**：面板 → 邮件页，每封邮件左侧「正文」按钮可就地展开纯文本正文（可复制、滚动位置记忆）。
- **更新角标**：有新版本时状态点旁出现绿色「↑」徽章（脉冲两次后常亮），点击展开面板查看。

## 交互与流畅性

- 面板展开/收起不再有工具栏残影与抖动（方向感知时序）。
- 快速连点展开/收起不再被吞（合并末次意图）。
- 切换刘海/胶囊/工具栏不再出现未响应（修复主线程锁互等）。
- 欧利整个身体（含头部）都可点击打开公司页面。
- 未读红点脉冲 3 次转常亮；菜单/状态卡关闭带淡出；设置窗口打开带淡入。

## 升级方式

- 已安装 0.5.0 或更新版本：设置 → 关于 → 检查更新，或等托盘自动提醒。
- 更早版本：直接手动安装本包，选原安装目录，不必先卸载。
- 更新签名属于 Tauri updater 校验，不是 Windows Authenticode，系统可能显示未知发布者提示。
