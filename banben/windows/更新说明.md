# 卖家岛 0.5.2 · Windows x64

本仓库仅发布卖家岛安装包和签名更新信息，不包含店铺配置、邮箱凭据、开发日志或更新私钥。

## 本次更新

- 新增 Windows 底部工具栏形态，类似输入法悬浮工具栏；工具栏可自由拖动，拖动后经营面板从当前位置向上展开。
- 工具栏模式下 Ollie（欧利）放大为原来的 2 倍，位于信息条上方，视觉上像坐在销售与风险信息条上。
- 工具栏信息条按内容收缩，欧利横向对齐“风险已知”，减少信息条右侧空黑区域。
- 修复收起胶囊 HTML 结构错误导致的小刘海、灵动岛和工具栏内容错位。
- 新增显示位置偏好，旧版小刘海/灵动岛配置自动兼容；工具栏支持不同宠物尺寸、DPI、跨显示器和拖动 anchor。

## 安装与升级

1. 下载同目录的 `卖家岛_0.5.2_x64-setup.exe`，确认来源为 `kid1419/maijiadao`。
2. 已有旧版时先从托盘完全退出卖家岛，再安装到原目录。不要先卸载，以免删除本地配置。
3. 0.5.0 及以后版本可在“设置 → 关于”检查并下载安装本更新；0.4.7 及更早版本没有更新器，可直接手动安装当前 0.5.2，无需先找 0.5.0。
4. 更新签名用于应用内校验，不等同于 Windows Authenticode 签名；Windows 仍可能显示未知发布者提示。
