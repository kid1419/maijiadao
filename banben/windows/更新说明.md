# 卖家岛 0.5.1 · Windows x64

本仓库仅发布卖家岛安装包和签名更新信息，不包含店铺配置、邮箱凭据、开发日志或更新私钥。

## 本次更新

- 店铺名与销售额之间新增滚动信息栏：北京时间与西雅图时间上下翻页展示，放得下时静止显示、始终清晰。
- 可选开启汇率页：主货币金额换算两种辅货币；汇率来自免费公共接口，约每 6 小时更新并本地缓存，联网失败沿用缓存，显示为日更级别数据。
- 可选开启活动倒计时：会员日、黑五、网一、秒杀、聚划算、店铺促销六种类型，填写开始与结束时间（按北京时间理解），最多 5 条；开始前倒计时，进行中显示剩余，结束后自动隐藏。
- 设置 → 外形与提示 → 实时活动中集中管理：胶囊滚动信息总开关下挂汇率与活动子开关，开启后才显示各自配置，改动即时保存。
- 时间、汇率与活动倒计时之间以上下翻页轮播切换；单条内容超出可用宽度时才水平滚动，悬停暂停。

## 安装与升级

1. 下载同目录的 `卖家岛_0.5.1_x64-setup.exe`，确认来源为 `kid1419/maijiadao`。
2. 已有旧版时先从托盘完全退出卖家岛，再安装到原目录。不要先卸载，以免删除本地配置。
3. 0.5.0 及以后版本可在“设置 → 关于”检查并下载安装本更新；0.4.7 及更早版本需要先手动安装一次 0.5.0 再升级。
4. 更新签名用于应用内校验，不等同于 Windows Authenticode 签名；Windows 仍可能显示未知发布者提示。
