# 卖家岛 0.5.0 · Windows x64

本仓库仅发布卖家岛安装包和签名更新信息，不包含店铺配置、邮箱凭据、开发日志或更新私钥。

## 本次更新

- 小刘海与灵动岛两种造型，点击展开经营面板。
- 一体化深色设置窗口，统一导航、字号、卡片和切换动效。
- Ollie（欧利）六个日常动作：呼吸、眨眼、摇耳摆尾、喝水、打哈欠和睡觉。
- 点击欧利打开公司内网页面；无法连接时给出轻量提示。
- 可在通用设置中选择网页使用的浏览器，统一用于欧利和运营详情等入口。
- 关于页支持检查更新、下载进度、版本绑定签名校验，以及用户确认后的安装与重启。
- 自动检查更新可关闭；不会自动下载或静默安装。

## 安装与升级

1. 下载同目录的 `卖家岛_0.5.0_x64-setup.exe`，确认来源为 `kid1419/maijiadao`。
2. 已有旧版时先从托盘完全退出卖家岛，再安装到原目录。不要先卸载，以免删除本地配置。
3. **0.4.7 及更早版本需要先手动安装一次 0.5.0。** 从 0.5.0 开始，后续正式版可在“设置 → 关于”检查并下载安装。
4. 更新签名用于应用内校验，不等同于 Windows Authenticode 签名；Windows 仍可能显示未知发布者提示。
5. 应用内安装会先等待保存完成，再退出程序运行安装器；有未保存的连接设置时会阻止安装。

## 版本文件

- `latest.json`：最新正式版本、发行说明、Windows x64 安装包地址与签名。
- `卖家岛_0.5.0_x64-setup.exe.sig`：对应安装包的版本绑定更新签名。
- `SHA256SUMS.txt`：文件完整性校验值；应用内安全校验以签名为准。

安装包仅包含程序及其界面资源，不内置任何领星 Key 或邮箱账号/授权码。请在本机设置中填写自己的连接信息。
