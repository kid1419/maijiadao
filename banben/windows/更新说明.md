# 卖家岛 0.5.5 更新说明

**发布日期**：2026-11-26
**安装包**：卖家岛_0.5.5_x64-setup.exe（10,717,390 字节）
**SHA256**：EFDD1B9EE9CAF79B21CA724C38B585BF1BDCA648A62A6233A3B583787E31CCC6

## 本轮新功能

- **邮件正文翻译（百度）**：邮件页展开正文后出现「翻译为中文」按钮，按需触发、不自动批量；完成后可「查看原文/查看中文」切换，两侧各自记忆滚动位置。长正文自动分块；重复阅读与缓存命中不再消耗额度。需在 设置 → 通用 → 邮件翻译 中填入百度翻译 APPID 与密钥（只保存在本机配置，界面不回显）。本机按月记账（默认上限 100 万字符），本机超额、百度余额不足、鉴权/限流分别提示；额度数据仅统计本机，不等于百度账户实时余额。
- **Mac 服务独立地址（局域网适配）**：设置 → 通用 → Mac 服务，可单独配置比价/库存/提醒服务地址（默认局域网地址，兼容旧 Tailscale 地址）；与领星 Key、店铺、邮箱表单分开保存。
- **人工提醒链接原生重建**：提醒点击不再把远端返回的地址直接交给浏览器，而是核对白名单后用本机可信地址重建，防篡改；人工处理提醒保持全局，不按当前店铺过滤。

## 信息条阅读体验

- 短文字静止 6 秒；长文字先停 1 秒、以 20px/s 滚到末尾完整可见、尾停 1 秒，再切下一页。
- 悬停同时暂停计时与滚动，移开继续读；程序在后台时暂停；开启"减少动态效果"时静态显示不滚动。

## 升级方式

- 已安装 0.5.0 或更新版本：设置 → 关于 → 检查更新，或等托盘自动提醒。
- 更早版本：直接手动安装本包，选原安装目录，不必先卸载。
- 更新签名属于 Tauri updater 校验，不是 Windows Authenticode，系统可能显示未知发布者提示。
