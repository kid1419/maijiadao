# 卖家岛 0.5.6 更新说明

**发布日期**：2026-11-27
**安装包**：卖家岛_0.5.6_x64-setup.exe（10,706,442 字节）
**SHA256**：D037A61F188DCDCCCF68761F2BD3C50683D6572D409C45FFFE6D4F7B65E7B83F

## 本轮新功能

- **FBA 库容页**：经营面板新增「库容」页签（账户与邮件之间），标准/服装/大件三类仓储各一张卡——大百分比、右侧容量柱、底部构成条，颜色对照系统性能页风格。
- **未来三个月切换**：「本月 / 12月 / 1月 / 2月」分段切换，三类同步；本月看实际占用，未来月看当前货量相对该月上限的压力，超上限整卡变红并显示超容量。
- **口径说明**：使用率 = 当前货件占用（在库+在途）÷ 所选月份的总容量；未来月份不把建议补货量计入，避免虚高。
- **数据来源**：领星 ERP 补货限制（需在领星安装领星插件或客户端采集）；采集不到时卡片会提示，安装插件后每 30 分钟自动更新。

## 自动更新改进

- 启动约 20 秒后自动检查一次更新（5 分钟内重复重启不重复查），此后每 6 小时检查；失败 15 分钟后重试。
- 发现新版本后，胶囊 / 刘海 / 工具栏会出现「有新版本」提示；即使后台复查失败也不消失。下载与安装仍在 设置 → 关于 中手动确认。
- 「设置 → 外形与提示 → 自动检查更新」开关可关闭自动检查。

## 升级方式

- 已安装 0.5.0 或更新版本：设置 → 关于 → 检查更新，或等启动后自动提示。
- 更早版本：直接手动安装本包，选原安装目录，不必先卸载。
- 更新签名属于 Tauri updater 校验，不是 Windows Authenticode，系统可能显示未知发布者提示。
