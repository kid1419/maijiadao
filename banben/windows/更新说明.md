# 卖家岛 0.5.7 更新说明

**发布日期**：2026-11-28
**安装包**：卖家岛_0.5.7_x64-setup.exe（10,737,136 字节）
**SHA256**：7D0990A580D5A83E3700F948B7776F2A1E33A3D22F6ED48CF759A1FC12F2B84E

## 本轮新功能

- **产品洞察滚动播报**：胶囊 / 刘海 / 工具栏的时间与汇率轮播中新增洞察任务动态——新批次优先显示，同一批次随进度原位更新（进行中 x/N → 完成 / 停止），保留服务端给出的失败原因。
- **断线更可靠**：接口超时或异常时保留上一次内容并标注「状态待确认」，恢复后自动继续更新；同一批次不会重复堆叠。
- **独立显示开关**：设置 → 外形与提示 → 实时活动 → 胶囊滚动信息，在北京/西雅图时间与汇率之间新增「产品洞察动态」开关，默认开启、自动保存；关闭只隐藏洞察播报，时间和汇率照常。

## 说明

- 洞察数据来自 Mac 端产品洞察服务（与采集提醒同一约 30 秒只读轮询，不额外增加请求频率）。
- 无进行中任务时显示最近完成 / 停止的批次记录；没有任何记录时不占位。
- 点击洞察滚动文字仍是展开经营面板，不触发任何采集或提交操作。

## 升级方式

- 已安装 0.5.0 或更新版本：设置 → 关于 → 检查更新，或等启动后自动提示。
- 更早版本：直接手动安装本包，选原安装目录，不必先卸载。
- 更新签名属于 Tauri updater 校验，不是 Windows Authenticode，系统可能显示未知发布者提示。
